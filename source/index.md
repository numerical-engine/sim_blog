# ゼロから始める自作CAE Simulation
このブログではCAE Simulationを自作するために必要な知識等を整理していきたいと思います(以後はSim.と書くことにします)。自己紹介をさせて頂きますと、私は主に企業のR&D組織(Sim.系の企業ではない)に所属していて、
* 市販のソフトでは対応していないSim.を実装し社内に展開
* 自作Sim.とAI技術を連携し、データドリブンな計算手法の研究

などを担当してきました。Sim.の本流を開発してきたという訳ではないので、プロの方はブログの内容を大目に見て頂ければと思います。その代わり基本的な内容を知識ゼロからでも分かるよう丁寧に説明していこうと思います(ただし基本的な数学や連続体力学の知識は前提とさせていただきます。本ブログで説明しきれない内容については参考書籍を紹介するようにします)。

なお扱う物理現象は連続体力学で描像されるものとします。そのため紹介するSim.手法も有限差分法や有限体積法、並びに有限要素法などです。原子や分子のSim.といったもの、つまりDFTやMDと呼ばれるものについては扱いません。またコーディングではPythonを使用します。基本的にライブラリを使用せず、ゼロから実装していくことを目指します。
